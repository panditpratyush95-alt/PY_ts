Introduction to Arduino

Arduino is an open-source electronics platform based on easy-to-use hardware and software. It consists of microcontroller boards (like Arduino UNO) that can be programmed to read inputs from sensors and control outputs like lights and motors.

It is widely used for DIY electronics projects, prototyping, robotics, home automation, and learning programming.

⭐ Why Choose Arduino?

💸 Inexpensive

Low-cost boards accessible to students and hobbyists worldwide.

🖥️ Cross-Platform

Works on Windows, macOS, and Linux operating systems.

🧩 Simple IDE

Beginner-friendly programming environment with rich library support.

🔓 Open Source

Both the hardware and software are open source and extensible.

🌍 Large Community

Millions of users, tutorials, and pre-built libraries available online.

⚡ Fast Prototyping

Go from idea to working prototype in minutes.

Introduction › Arduino Uno R3
🔌

Arduino Uno R3 Board

The Arduino Uno R3 is based on the ATmega328P microcontroller. It is the most widely used Arduino board for education and prototyping due to its simplicity.

It comes in two variants: DIP (through-hole chip, easy to replace) and SMD (surface-mount, compact for production).

📊 Key Specifications

FeatureValue
MicrocontrollerATmega328P
Operating Voltage5V
Input Voltage (Recommended)7–12V
Input Voltage (Limits)6–20V
Digital I/O Pins14 (6 PWM outputs)
Analog Input Pins6 (A0–A5)
DC Current per I/O Pin40 mA
DC Current for 3.3V Pin50 mA
Flash Memory32 KB (0.5 KB used by bootloader)
SRAM2 KB
EEPROM1 KB
Clock Speed16 MHz

📌 Pin Description

Pins 0 (RX) & 1 (TX)

Serial communication — receive and transmit TTL data.

Pins 2 & 3 (INT)

External interrupts — trigger on LOW, rising/falling edge, or change.

Pins 3,5,6,9,10,11 (~)

PWM output — 8-bit pulse width modulation (0–255).

Pins 10–13 (SPI)

SPI communication: SS, MOSI, MISO, SCK.

Pin 13 (LED)

Built-in LED connected to digital pin 13.

A0–A5 (Analog)

10-bit analog inputs: 1024 values (0–1023).

A4 (SDA) & A5 (SCL)

I2C / TWI communication interface.

AREF

Reference voltage for analog inputs.

RESET

Pull LOW to reset the microcontroller.

💡

DIP vs SMD: For beginners, the DIP version is preferred as the ATmega328P chip can be easily removed and replaced. The SMD version is more compact and suited for production.

Introduction › Setting Up Arduino IDE
💻

Setting Up Arduino IDE

The Arduino IDE (Integrated Development Environment) is a free, cross-platform tool that lets you write code (called "sketches") and upload them to your Arduino board with a single click.

📥 Step-by-Step Installation

  • 1
    Download the Arduino IDE

    Visit arduino.cc/en/software and select your OS (Windows / macOS / Linux).

  • 2
    Install on Windows
    • Run the downloaded .exe installer.
    • Follow the wizard — accept license, choose components (install all recommended).
    • Click Finish when complete.
  • 3
    Install on macOS
    • Open the downloaded .dmg file.
    • Drag the Arduino icon into Applications folder.
    • Launch from Applications.
  • 4
    Install on Linux
    • Extract the downloaded archive.
    • Open terminal, navigate to the folder.
    • Run: sudo ./install.sh
    • Launch by typing arduino in terminal.
✅

Pro Tip: Always install the latest stable version of Arduino IDE 2.x for syntax highlighting, auto-complete, and integrated Serial Plotter.

🧑‍💻

Arduino Programming Basics

Arduino programs are called sketches and are written in C/C++. Every sketch must contain two core functions:

🔧 Sketch Structure

Arduino C++ — Basic Sketch Structure
// ---- Global variables & pin definitions go here ----
const int LED_PIN = 13;

// setup() runs ONCE on power-up or reset
void setup() {
  pinMode(LED_PIN, OUTPUT);   // Configure pin 13 as output
  Serial.begin(9600);          // Start serial monitor at 9600 baud
}

// loop() runs FOREVER after setup() completes
void loop() {
  digitalWrite(LED_PIN, HIGH); // Turn LED ON
  delay(1000);                  // Wait 1000ms (1 second)
  digitalWrite(LED_PIN, LOW);  // Turn LED OFF
  delay(1000);                  // Wait 1 second
}

Remember: setup() runs only once at startup. loop() repeats forever. All your sensor reading and output control logic goes inside loop().

Introduction › Board Bring-Up
🚀

Arduino Board Bring-Up

Follow these steps every time you start a new Arduino project to ensure your board is correctly connected and configured.

  • 1
    Connect Arduino to Computer

    Use a USB-A to USB-B cable (or USB-C for newer boards). Plug one end into the Arduino and the other into your PC. The power LED on the board should light up.

  • 2
    Open the Arduino IDE

    Launch the Arduino IDE on your computer. You will see the default empty sketch with setup() and loop().

  • 3
    Select the Board

    Go to Tools → Board → Arduino AVR Boards → Arduino Uno.

  • 4
    Select the Serial Port

    Go to Tools → Port and select:
    • Windows: COM3 (or similar)
    • macOS: /dev/tty.usbmodemXXXX
    • Linux: /dev/ttyACM0

  • 5
    Open the Blink Example

    Go to File → Examples → 01.Basics → Blink. This opens the built-in LED blink sketch.

  • 6
    Upload the Sketch

    Click the Upload button (→). The IDE will compile and upload. The built-in LED on Pin 13 should blink once per second — your board is working!

🔧 Troubleshooting

  • If the port is not detected, try a different USB cable (use a data cable, not charge-only).
  • On Windows, install CH340 or CP2102 USB-Serial drivers if the port doesn't appear.
  • Restart the Arduino IDE after plugging in the board.
  • Ensure no other program is using the same COM port.
